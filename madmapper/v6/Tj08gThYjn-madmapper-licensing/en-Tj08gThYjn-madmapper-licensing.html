MadMapper Licensing

Seats = Computers

In the MadMapper licensing system, computers are referred to as seats. One seat = one computer, whether Mac or PC.

The number of seats included in a license determines how many devices can run MadMapper simultaneously. For example, a 2-seat license allows you to use MadMapper on two computers at the same time.

For this last example, if you have to use the MadMapper on a third computer, you will need to log out one of the current authorized computers first.

Temporary vs Perpetual

Temporary Licenses

Temporary licenses let you select both the number of seats and the duration for which the license will be active.

You can start with a minimum of 1 seat for 1 month.

Temporary licenses never renew automatically.

They expire at the end of the selected term, you'll have to grab a new one if you still need to use MadMapper.

Perpetual Licenses

Perpetual licenses are lifetime licenses that do not expire. They are designed for long-term use and start with a minimum of 2 seats, up to 20.

You can store an unlimited number of licenses in your MadMapper account, whether they are temporary or perpetual, making it easy to manage multiple projects or teams from a single account.

EDUCATION Licenses

EDUCATION licenses are available in both temporary and perpetual versions and are identical in every way to their standard license equivalents.

These licenses are offered at a discount to support students, teachers, and schools in learning MadMapper.

To apply for the EDUCATION offer, please visit this page: https://madmapper.com/education

Licenses Generation

Purchases

Upon receipt of payment, the license will be generated and the serial number will be added to the MadMapper account that made the purchase.

At this point you will be able to Download and authorize MadMapper or its extensions.

The rental period for a temporary license begins when the license is first authorized on a computer.

License Import and Redeem Keys

Licenses are generated automatically from a redeem key. The same applies to importing licenses prior to version 5.

If you receive an error message, please contact us at support.

Features

The software features are identical across all license types - temporary, perpetual, and EDUCATION.

Regardless of the license you choose, you will have access to the same full set of tools and capabilities in MadMapper.

The features of MadLaser and other MadMapper extensions are not included with the main MadMapper license.

These extensions require a separate license to be used. Their licensing process and principles are identical to those of MadMapper.

Updates and Upgrades

All updates released within the same major version of MadMapper are free. These include performance improvements, bug fixes, and feature additions.

When switching to a new version, an upgrade fee applies, ie. upgrading a license from v5 to v6.

There is no obligation to upgrade a license unless you wish to use features introduced in a newer version of MadMapper.

Your existing license will continue to work with the version it was purchased for.

Extensions Versions

MadLaser and MadProjectorControl are extensions of MadMapper. In order to use them, you will need an additional license.

Extension licenses work in the same way as MadMapper licenses, see about seats, temporary, perpetual, etc. above.

 

They require MadMapper to be installed and the extensions to be authorized.

You can authorize or deauthorize (log in or log out) extensions at any time using the Authorization Manager.

You cannot use MadLaser or MadProjectorControl as standalone applications.

You must own a MadMapper license, either temporary or perpetual.

MadAI Credits

MadAI credits are used to generate content through prompts.

The credits purchased to make requests to MadAI Artificial Intelligence are linked to your MadMapper User Account.

Can't see the credits you purchased in MadMapper?
Check your purchase in your account on the website, also check that you are properly logged into MadMapper, with the correct account.

Demo Version

The Demo version of MadMapper is free and does not require any license to run.

It allows users to explore the software and its interface freely.

 

It is not a version aimed to professional work and it comes with several limitations such as:

  • Watermark shown on input, output and output preview.
  • Loading/saving a project is disabled.
  • Export to SVG/PNG/PDF is disabled.
  • Spacial Scanner is limited and cropped to 1/4th of its resolution.
  • DMX lighting devices will blackout once every 30 seconds.
  • Material installation and publishing from the library is disabled.
  • MadAI is not supported.

Despite these restrictions, the Demo version can be used indefinitely, making it ideal for testing and learning.

Please note that because the Demo version does not use the licensing system, it is not possible to authorize or deauthorize it.

If you purchase MadMapper, you will need to download and install the full licensed version.
