MadMapper Preferences

The Preferences menu (Cmd + , on Mac / Ctrl + , on PC) dictates the foundational behavior of the software. MadMapper 6 splits these preferences into two distinct tabs: Application (global settings that affect the software overall) and Project (settings saved specifically to the .mad file you currently have open).

Application Tab

These settings govern how the MadMapper application behaves on your specific computer, regardless of which project file is open.

Startup

Configure the initial User Interface state upon launch. Options include Always Minimize at startup, enabling Silent Mode (which suppresses user prompts—highly recommended for permanent installations), and toggling the Open Project dialog at startup.

General

Manage your safety net and UI features.

  • AutoSave & Backups: Enable AutoSave and define its interval (in minutes), and set the maximum number of automatic Project Backups.

  • Master: Choose whether to Reset Master settings on new project.

  • User Interface: Toggle Enable Expert Mode to expose advanced routing and programming features throughout the software.

  • MadAI: Enable Update Resource Thumbnail on Edition to automatically refresh generated previews.

Devices

The control center for external hardware inputs.

  • Video Input: Automatically check for connected devices, and enable native support for Blackmagic capture cards (including options to show all system-compliant devices and display outdated driver warnings), Canon EDSDK cameras, Kinect ONE depth sensors, and Intel RealSense.

  • Controls: Toggle support for external control peripherals, including Stream Decks, GamePads, and Makey Makey forwarding (which maps external inputs to arrow keys and other software triggers).

DMX

Adjust how lighting fixtures are handled in the user interface. You can choose to Show Master DMX Color, force MadMapper to Always draw fixtures pixels (even when unselected), and enable Automatically choose DMX address for duplicated / pasted fixture.

Audio

Manage your global audio routing.

  • Audio Settings: Select your specific Audio Input, Audio Analysis Channels, Audio Output, Sample Rate, and Buffer Size.

  • Audio Data: A read-only diagnostic window that provides a live status report of your active audio devices, channels, mixdown levels, and individual channel levels.

Engine

Manage backend rendering behaviors and preview quality.

  • Rendering: Displays your active GPU. You can toggle Use Double-Buffered Previews (which prevents screen tearing but impacts overall performance) and enable high-quality previews for Retina displays.

  • Media: Choose to enable audio playback by default, and define the default rendering resolution and frame rate for Image Folders.

Laser

See MadLaser Preferences for more details.

Enable global hardware protocols for your laser projectors.

  • Enable Audio Laser (AVB / Dante): Checking this box unlocks the ability to control laser projectors through audio output via an AVB or Dante network. Instead of using a standard ILDA DAC, MadMapper sends the X, Y, Red, Green, and Blue positional and color data directly to an AVB audio card as if it were an audio stream. This requires a compatible AVB network switch to guarantee bandwidth and an AVB audio interface (such as the RME Digiface AVB). Using AVB provides highly reliable signal transmission and allows for the perfect synchronization of multiple laser devices on the network.

  • Audio Device: Select your specific AVB or Dante network audio card. Note: On Windows, enabling AVB will force MadMapper to switch the audio driver type to ASIO and will require an application restart.

  • Sample Rate: Defines the transmission speed (e.g., 48000Hz or 96000Hz). You must ensure this exactly matches the sample rate set on your physical AVB / laser projector hardware.

  • Buffer Size: Set the network audio buffer (e.g., 192 samples).

  • Device Count: Allows you to choose the number of virtual AVB outputs you want to create, enabling you to drive multiple separate lasers from a single audio interface.

  • Audio Channels per Unit: Defines the number of audio channels dedicated to a single laser. This is typically set to 5 channels, representing the physical electrical signals required for X, Y, Red, Green, and Blue.

  • Enable Scene Markers: Toggle visibility for audio timeline markers.

  • Status Box: Provides a live diagnostic readout to confirm if the audio device is running properly and how many audio channels have been successfully started by the software.

Note: For a comprehensive guide on setting up your network switch, audio card, and hardware routing, the official MadLaser AVB Support guide can be found directly inside the software by navigating to the top menu and selecting Help > MadLaser User Guides > Mad Laser AVB Output.

Project Tab

These settings are saved directly into your current project workspace and will travel with the project if you move the project file to another computer.

Startup

Automate actions that should occur the moment this specific project is opened. Options include forcing the project into Fullscreen video mode upon opening, or automatically arming connected Laser projectors.

General

Manage project-level master recall behaviors.

  • Master: Choose whether to Restore Master Settings from Project when the file is loaded.

MIDI

Configure your project-specific MIDI routing and feedback.

  • MIDI Inputs: Select specific Input Devices and their corresponding Feedback Devices to keep MIDI controllers (like motorized faders or LED buttons) in sync with MadMapper. You can also choose to use note velocity when mapping.

  • MIDI Outputs: Define dedicated outgoing MIDI devices and names to trigger external hardware or software.

OSC

Manage incoming and outgoing Open Sound Control network data.

  • OSC Input: Set your listening Input Port (default 8010) and Feedback Port (default 9000). You can toggle Enable Bonjour Discovery for automatic network configuration and define a custom Feedback IP.

  • OSC Outputs: Create and manage a list of targeted outgoing OSC connections by defining their Name, IP, Port, and Bonjour status.

DMX

Configure incoming and outgoing lighting control data. MadMapper natively supports network protocols like Art-Net and sACN, as well as physical USB DMX interfaces (including the official MadMapper/GarageCube USB DMX controller, ShowJockey, Enttec DMX USB Pro, Enttec DMX USB Pro MK2, and any Enttec Pro compatible USB DMX device such as the DMX King eDMX2 Pro).

  • DMX Input: Define your listening device (e.g., ArtNet In), select the specific network interface, and set the listening universe.

  • DMX Output: Select your output protocol or physical device and target network interface. You can cap the Maximum FPS to optimize network traffic, enable Unicast routing, toggle Universe Synchronization, and utilize the built-in node scanner to auto-poll for active Art-Net devices on your network.

Engine

Project-specific rendering parameters for playback and media processing.

  • Rendering: Lock the Engine FPS to a specific frame rate or leave it on Auto to match your display.

  • Media: Globally toggle the Media Anti Aliasing filter for the project.

Timelines

Manage timeline playback conditions and legacy storage behaviors.

  • Playback & Storage: Options include automatically stopping active timelines when switching to a different Bank, and defining whether DMX Fixtures and Surface Output Geometries should be explicitly stored when recording legacy Scenes.

Laser

See MadLaser Preferences for more details.

This sub-menu contains critical safety and visualization settings for your project's laser outputs.

  • Security: Unlock Security Features to define the Max non-moving Beam Intensity (a critical safety parameter to prevent hardware damage or audience hazards) and enable Expert Mode Settings for advanced laser routing.

  • Visualisation: Route laser data over the network to supported external 3D visualizers like Capture.

  • Beam Preview: Adjust the internal rendering of the laser preview within the software UI. Options include setting the Beam Level (brightness), adjusting the Beam Origin X/Y coordinates to simulate the physical projector's location, toggling End Beam on path, and enabling a simulated Fog effect for accurate 3D previewing.
