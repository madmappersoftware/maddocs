MadMapper Preferences

The Preferences menu (Cmd + , on Mac / Ctrl + , on PC) dictates the foundational behavior of the software. MadMapper 6 splits these preferences into two distinct tabs: Application (global settings that affect the software overall) and Project (settings saved specifically to the .mad file you currently have open).

Application Tab

These settings govern how the MadMapper application behaves on your specific computer, regardless of which project file is open.

  • Startup: Configure the initial User Interface state upon launch. Options include minimizing the application on startup, enabling Silent Mode (which suppresses user prompts—highly recommended for permanent installations), and toggling the "Open Project" dialog box.

  • General: Manage your safety net and UI features. Here you can enable AutoSave and define its interval, set the maximum number of Project Backups, toggle Expert Mode in the UI, and enable automatic thumbnail updates for Mad AI resources.

  • Devices: The control center for external hardware.

    • Video Input: Enable native support for Blackmagic capture devices, Canon EDSDK cameras, Kinect ONE depth sensors, and Intel RealSense.

    • Controls: Toggle support for external control peripherals including Stream Decks, GamePads, and Makey Makey forwarding.

  • DMX: Adjust how lighting fixtures are handled in the interface. You can choose to show Master DMX color, force MadMapper to always draw fixture pixels (even when unselected), and enable automatic DMX addressing when duplicating or pasting fixtures.

  • Audio & Engine: Manage global audio routing and backend rendering behaviors.

  • Laser: Enable global hardware protocols, such as Audio Laser over AVB/Dante networks.

Project Tab

These settings are saved directly into your current .mad file and will travel with the project if you move it to another computer.

  • Startup: Automate actions that should happen the moment this specific project is opened. You can set the project to automatically enter Fullscreen video mode, or automatically Arm Lasers.

  • General / MIDI / OSC / DMX / Engine: Configure project-specific network addresses, engine frame-rates, and control routing.

  • Timelines: Manage timeline playback and storage behaviors. Options include stopping timelines when switching Banks, and defining whether DMX Fixtures and Surface Output Geometries should be stored inside legacy Scenes.

  • Laser: This sub-menu contains critical safety and visualization settings for your laser outputs.

    • Security: Unlock advanced security features, define the Maximum non-moving Beam Intensity (a critical safety parameter for live audiences), and enable Expert Mode settings.

    • Visualisation: Route laser data to external visualizers like Capture.

    • Beam Preview: Adjust the internal rendering of the laser preview, including Beam Level, Origin parameters, path endings, and simulated Fog visibility.
