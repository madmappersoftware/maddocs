Update MadMapper

You do not need to log out your license before installing a MadMapper update on the same computer.

 

Updates are checked automatically, and if a new version is available you will be notified when you open MadMapper.

Once the installation file for the latest version has been downloaded, you can begin the installation process.

If you install a MadMapper update, it will not replace previous versions of MadMapper already installed on your computer.

You can have multiple different versions of MadMapper installed on your computer.
