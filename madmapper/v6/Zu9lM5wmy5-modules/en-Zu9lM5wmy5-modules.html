Timeline Scheduler

 

Timeline Scheduler ensure a timeline get started when we’re inside the time range, between Start time (hour/minute/seconds) & End time, if the “Date” settings matches current day.

 

In Depth:

 

The timeline (a scene or a cue, animated or not) will be started when:

  • Loading the project and we’re inside the time range.
  • When entering the time range (because time elapses or because we’re editing Start/End time).

The timeline will be stopped when:

  • Leaving the time range (because time elapses or because we’re editing Start/End time) while the timeline was started by this same module.

If "End/Stop on Loop End” is enabled, the timeline will be paused when reaching loop end (except if playhead is after loop end).

 

If the target bank is not the current bank, the scheduler will not change current bank but it will start the timeline in the desired bank.

When timeline is started, if grid has horizontal or grid exclusivity, it will be handled, like if user clicked the play button.

So End time doesn’t change anything for a non animated scene or cue, except when loading project (so on computer startup in an fixed installation with project loading at computer start).
