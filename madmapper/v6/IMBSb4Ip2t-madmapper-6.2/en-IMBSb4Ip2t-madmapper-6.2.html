What's New in MadMapper 6.2

Projects saved with MadMapper 6.2 cannot be opened with MadMapper 6.1 or older.
Keep a copy of your project before opening it in 6.2 if you might need to go back. Projects from 6.0, 6.1 and MadMapper 5 are converted automatically when opened.

Tasks and the GO button

  • A Task is a column of a Grid: the Scenes and Cues it contains start together. Tasks have names, durations and next-task rules (follow, jump, random), and the big GO button starts the next one, so an operator can advance a show that does not follow a fixed timeline (theatre, events, installations reacting to the audience).
  • Tasks can also be started from Controls and OSC: /show/<Bank>/tasks/go, start_next, start_previous, start_by_number, by_number/<N>/start, by_name/<Task>/start and by_name/<Task>/alternate_next/<Target Task>.

Show Sequencer (formerly Timelines)

The Timelines editor is now called the Show Sequencer. It keeps all the concepts introduced in 6.0 (Conductor, Grid, Scenes, Cues, Timelines) and adds:

  • Separate banks for Conductors and Grids. Conductors and Grids now live in different banks, and a Conductor can reference Scenes and Cues from any Grid bank.
  • Equalizer on audio tracks. Each audio track of a timeline has its own equalizer, and can also host audio plugins.
  • MadLight tracks. Add MadLight Track adds a track that plays recorded DMX sequences as clips, and can record DMX (for example all incoming Art-Net) into a new clip.
  • OSC Query tracks. Add OSC Track›OSC Query... connects to an OSC Query server, lists the parameters it publishes and creates OSC tracks for them.
  • Audio level linked to opacity on Montage clips. The audio level of a movie in a Montage clip can follow the opacity of the surface (Link Audio level to surface opacity), so visual fades also fade the sound.
  • Start Point. A start marker defines where playback starts when you start a timeline, independently of its loop.
  • Grid Orientation. A Grid can be flipped to swap columns and rows.
  • Timecode monitor. When a Conductor is synchronised to an external timecode (ExtSync), the Timecode Monitor… button opens a window that shows the incoming timecode.

New Media Types and Integrations

  • Notch blocks (Windows only) : Load a Notch block (.dfxdll file) as a media, and control its exposed parameters from the media inspector. Windows only.
  • TouchDesigner : Load a TouchDesigner component (.tox file) as a module: its parameters appear in the module inspector and its Out TOPs appear as media. The TouchDesigner license is checked before a .tox file is loaded.
  • WebPage : Use any web page as an interactive media: set its URL and size, and interact with it from MadMapper.
  • Window Grabber media : Capture the window of another application and use it as a media, for example a presentation, a browser or a dashboard.
  • Subtitles : When a movie contains text subtitle tracks, MadMapper can display a track over the video, or create a separate media that renders only the subtitle text (for a separate surface, an LED screen or a laser). .srt subtitle files can also be imported and played as media.
  • MediaPipe module : The MediaPipe module tracks hands, body or face in a camera image and outputs gesture values (positions, pinch and grab levels, poses, face expressions, head orientation) for interactive installations.

Audio

  • Audio plugins : Insert audio effect plugins on the master audio output and on Show Sequencer audio tracks: VST3 on macOS and Windows, Audio Unit on macOS.
  • Audio output level meters : The Master tab and Show Sequencer audio tracks show an Audio Output Levels meter of their output, after the audio filters, with a clip indicator.
  • Multichannel audio routing : Movies with 5.1 or 7.1 audio are now down-mixed more accurately when the output is mono or stereo.

DMX, LED and lighting

  • HSI and CIE xy color control : Fixture definitions can describe fixtures controlled in HSI (hue, saturation, intensity) or in CIE xy chromaticity coordinates, in addition to RGB-type color modes.
  • Art-Net FPS mode : A new FPS Mode option chooses between a fixed and a variable frame rate for Art-Net and sACN output. Fixed FPS is recommended for compatibility with most hardware.
  • All RGB orders for LED strips and matrices : Every combination of RGB order (RGB, RBG, GRB, GBR, BRG, BGR) is available by default for LED Strips and LED Matrices.

Controls

  • Device-specific MIDI controls : A MIDI control can be tied to one MIDI device, so the same note or controller number on two devices can drive two different parameters. Set it in Project›Project Settings, MIDI tab, MIDI Input › Mapping Device.

Outputs and surfaces

  • Output buttons in Controls and Cues : The buttons of the output inspector (Desktop Window, Publish to Syphon / Publish to Spout, Publish to NDI, Show Test Pattern, Publish Internal Loopback) can be mapped to Controls and stored in Scenes and Cues.
  • Black level compensation : Soft-edge blending gains Black Level Compensation. Projectors cannot produce a true black: where two projectors overlap, their residual light adds up and the overlap looks brighter than the rest of a dark image. Black level compensation lifts the black level of the non-overlapping areas to hide this difference.
  • Ascii Art Surface FX : A new 2D Surface FX renders the surface content as characters (ASCII ramps, halftone blocks, matrix code, dot screens…), with adjustable character size, contrast, edge boost and colors.
  • Destination popups show screens in use : The Destination popup of Video Outputs and Laser Outputs now shows which screens and lasers are already used by another output (shown in bold italic).
  • Better constrained move : Shift+Drag on an item in a preview constrains the move to one axis. It now works with multi-selections and with mesh warping points.

Interface and projects

  • Expert Mode saved in the project : Expert Mode is now saved in the project: enable it in the Expert section of Project Settings. It reveals new advanced options for media, surfaces, outputs and the Show Sequencer.
  • Extract button in the editors panel header : The header of the editors panel has an extract button that opens the selected editor in its own window.
  • Higher interface contrast : The user interface uses higher contrast for better readability.
  • Project export as an archive : File›Export Project To... can produce a single .zip archive of the project and its resources, ready to send.
  • File type filters in the Import Media dialog : The File›Import Media... dialog has one filter per media family (Images, Movies, ISF Shaders…) and an All supported formats filter.
  • Saving in the Demo version : The Demo version can now save projects, for testing purposes. Projects saved by the Demo cannot be opened by a licensed MadMapper and vice versa.
  • Preferences window position : The Preferences window reopens at its previous position and size.

Performance

  • Images are loaded only when used, asynchronously. Projects with hundreds of images use far less memory and open faster.
  • Huge projects (many surfaces, fixtures and outputs) are handled faster.
  • The Canon EDSDK, used for Canon cameras as live inputs and by the Space Scanner is updated to version 13.20.20.0.

Converting older MadMapper 6 projects

When you open a project saved with MadMapper 6.0 or 6.1, MadMapper 6.2 converts it automatically:

Before 6.2 In 6.2
Timelines editor Show Sequencer
OSC and control addresses starting with /timelines/ Addresses starting with /show/
Grid columns and rows Tasks and lines (control addresses such as /by_cell/col_1/scene_row_2 become /by_cell/task_1/scenes_2)
Conductor stored in the same bank as the grid Conductor stored in its own bank, named after the grid bank with a _Conductor suffix (for example /show/Bank-1_Conductor/…)
Timeline Scheduler, Timeline Automation, Startup Timeline, Idle Timeline modules Show Scheduler, Show Automation, Show Startup, Show Idle modules, with their parameters renamed accordingly
Calendar Scheduler parameter Stop on Loop End Pause on Loop End

MadLight sequences are saved in the MadLightSequences folder of the project, one <name>.madlight folder per sequence.

Controls (MIDI, OSC, DMX, keyboard) and automation tracks that pointed to renamed items are remapped. If you control MadMapper from external software (show controllers, TouchOSC layouts, scripts), update the OSC addresses on that side.
