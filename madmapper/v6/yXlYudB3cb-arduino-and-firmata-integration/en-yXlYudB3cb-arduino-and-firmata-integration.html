Arduino & Firmata Integration

MadMapper supports direct, bidirectional communication with physical microcontrollers using the Firmata protocol. This allows you to easily route physical sensors, buttons, and potentiometers directly into MadMapper as control inputs, or send data out from MadMapper to trigger physical hardware like LEDs, motors, and relays.

Supported Boards & Hardware

  • Universal Compatibility: While the MadMapper interface explicitly highlights popular boards such as the Arduino Uno, Arduino Mega, and Teensy, the software does not check VendorID or ProductID. Therefore, any connected microcontroller that registers as a valid serial port on your computer will appear as an option.

  • The Rule of Thumb: If you can successfully upload the Standard Firmata sketch to your board via the Arduino IDE, you can use it to communicate with MadMapper.

Preparing the Microcontroller (Arduino IDE 2.x)

Before MadMapper can see your board, you must install the Firmata library onto it.

  1. Download and open the latest version of the official Arduino IDE (Version 2.x or newer).

  2. Connect your Arduino or microcontroller to your computer via USB.

  3. In the new Arduino IDE, look at the top toolbar. Click the Board Selection Dropdown and select your connected board and its corresponding serial port. (Note: Many official Arduino boards will be automatically detected and selected here).

  4. Navigate to the top menu and click File > Examples > Firmata > StandardFirmata.

    • (Note: If you are using an Arduino Mega or a Teensy, you must select StandardFirmataPlus instead).

  5. Click the Upload button (the right-pointing arrow in the top-left corner of the toolbar).

  6. Wait for the terminal at the bottom of the screen to display the "Done uploading" message. Once successful, close the Arduino IDE completely.

Connecting to MadMapper

Once the board is flashed with Firmata, you can connect it to your MadMapper project:

  1. Open the Modules tab (accessible from the top left of the main interface).

  2. Click the + (Plus) icon to add a new module and select Firmata.

  3. In the Firmata module's Configuration settings, use the Port dropdown to select your board's serial connection (e.g., /dev/cu.usbmodem... on Mac or COM3 on Windows).

  4. Select your exact Model (e.g., Arduino UNO) from the dropdown.

Working with Pins and Modes

Once connected, the module will display a list of all available Analog and Digital pins on your board. You can configure each pin's Mode based on what physical component is wired to it:

  • Analog Mode: Use this for variable physical sensors, such as photo-resistors or knobs. Any changes in voltage will instantly reflect in MadMapper as a continuous value.

  • Input Mode: Use this for simple digital switches and buttons (e.g., pressed vs. unpressed).

  • Output Mode: Use this to send a basic On/Off signal from MadMapper to trigger external hardware (like a relay or a simple LED).

  • PWM Mode (Pulse Width Modulation): Use this to send variable data out of MadMapper, such as smoothly dimming an LED's brightness intensity using a slider. (Note: On the Arduino UNO specifically, you cannot properly use PWM and Servo modes simultaneously due to hardware timer limitations).

  • Servo Mode: Use this to convert data from MadMapper into physical movement, driving the angle of a connected servo motor.

Mapping Firmata Controls

You can map any parameter in MadMapper directly to your physical Arduino sensors or actuators using the Control List.

  1. Right-click the parameter you want to link in MadMapper, and select Add Control > MadMapper > Firmata.

  2. Set the Source Device to Firmata.

  3. Select the specific Channel that corresponds to your pin (e.g., D7 State for a digital button, or A0 for an analog photo-resistor).

  4. Use the Source Range and Target Range sliders to scale the behavior. For example, you can map the true/false state of a physical button press to drive a value from 0 to 255, which could trigger an LED or rotate a servo motor exactly 180 degrees.
