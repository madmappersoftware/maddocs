ILDA Files

The ILDA format (.ild) is the universal standard for sharing and playing back pre-rendered laser graphics and animations. MadMapper fully supports importing and exporting ILDA files to integrate seamlessly with other laser workflows.

Importing ILDA Content

You can import .ild files directly into your Media Bin just like a standard video file. Once imported, simply drag and drop the ILDA file onto any active Laser Surface to play back the pre-rendered vector animation. Because ILDA files already contain exact X/Y coordinate and color data, they are incredibly efficient and bypass the need for real-time image tracing.

Exporting ILDA Content

If you use MadMapper's powerful generative engine to create custom laser shows, you can bake that content down into a static file for use on standalone media players or other laser software.

  • Via the Timeline: You can export sequences directly to ILDA via the Timeline export options.
  • High-Resolution Vectorization (Expert Mode): When Expert Mode is enabled, the video vectorization engine can process media up to 16k resolution. While real-time performance will degrade at 16k, this is an incredibly powerful feature for executing non-real-time conversions of massive video files into high-resolution ILDA exports.
