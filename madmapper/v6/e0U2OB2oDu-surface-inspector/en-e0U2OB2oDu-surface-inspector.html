Surface Inspector

The Surface Inspector, below the list of surfaces, displays the settings and parameters of the selected surface (highlighted in the surfaces list).

The settings may vary depending on the type of surface.

 

However, there are some settings and parameters that are common to all types of surfaces, as detailed below.

Media

Information about the media used by the surface:

 

Appearance

Gathers together so-called “standard” settings such Opacity, Blend Modes, Flip, Color.

FX (Effects)

The FX section allows you to apply different visual effects directly to your surface. The interface consists of an FX Type toggle to enable or disable the effect, followed by an FX dropdown menu to select the specific effect you want to use. The inspector below it automatically updates to display the adjustable values for your chosen FX.

By default, this is set to Color Controls, which allows you to adjust the media's basic color settings:

 

However, Color Controls are just one type of effect! MadMapper offers a massive library of publicly available 2D FX that can be downloaded and added directly to your layer. Furthermore, because these effects are built using the same MadMaterials GLSL code architecture, you can use MadAI to generate completely new, custom 2D FX using just text prompts—without writing a single line of code!

Mesh Warping

Mesh Warping is an essential technique enabling a grid mesh in order to warp the shape.

Add as many control points as needed. Create a new warping point by clicking Add Warping Point or right-click Add Warping Point on the surface itself.

 

Activate it here Bezier Mesh Warping in order to use bezier curves to change the shape into a complex surface.

 

By default, the Link Input and Output Mesh is enabled by default.  This means that if you adjust and points on the input side, the output mesh will mirror them.  To disable this you must first enable Show Input Mesh.

Specific Parameters

You will find specific settings depending on the type of Surface.

For example, the 3D surface Inspector comes with specific tools and parameters such as wireframe, lighting, edit UVs, etc.

With shift+select several surfaces, the Inspector will only display the common parameters of the selected surfaces.

Note that the percentage of a setting is multiplied by the group setting.
