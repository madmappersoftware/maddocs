MadMapper Licensing

Seats

In the MadMapper licensing system, computers are referred to as seats. The number of seats included in a license is a key detail, as it determines how many devices can run MadMapper simultaneously.

 

Each seat corresponds to one computer, whether Mac or PC, on which the software can be authorized and used at the same time.

 

For example, a 2-seat license allows you to run MadMapper on two computers simultaneously. If you try to use it on a third computer at the same time, you will need to de-authorize one of the existing seats first.

Temporary vs Perpetual

Temporary Licenses

Temporary licenses let you select both the number of seats and the duration for which the license will be active. You can start with a minimum of 1 seat for 1 month, giving flexibility to match your project or team needs.

Temporary licenses never renew automatically.

They expire at the end of the selected term, requiring another purchase if you wish to continue using MadMapper.

Perpetual Licenses

Perpetual licenses are lifetime licenses that do not expire. They are designed for long-term use and start with a minimum of 2 seats, up to 20.

You can store an unlimited number of licenses in your MadMapper account, whether they are temporary or perpetual, making it easy to manage multiple projects or teams from a single account.

EDU Licenses

EDUCATION licenses are available in both temporary and perpetual versions and are identical in every way to their standard license equivalents.

 

The only difference is the price: these licenses are offered at a discount to support students, teachers, and schools in learning and using MadMapper.

To apply for the EDUCATION offer, please visit this page: https://madmapper.com/education

Features

The software features are identical across all license types - temporary, perpetual, and EDUCATION.

 

Regardless of the license you choose, you will have access to the same full set of tools and capabilities in MadMapper.

The features of MadLaser and other MadMapper extensions are not included with the main MadMapper license.

These extensions require a separate license to be used. Their licensing process and principles are identical to those of MadMapper.

Versions

All updates released within the same major version of MadMapper are free. These include performance improvements, bug fixes, and feature additions.

 

When a new major version, an upgrade fee applies, ie. upgrading a license from v5 to v6.

There is no obligation to upgrade a license unless you wish to use one or more new features introduced in a newer version of MadMapper.

Your existing license will continue to work with the version it was purchased for.
