Scheduling & Automation

MadMapper provides a comprehensive suite of tools for sequencing, automation, and unattended operation. By leveraging various modules and timeline features, users can establish programmable cue scheduling, rules-based logic, and calendar-based triggers using standard ICS files.

Programmable Cue Scheduling & Automation

For dynamic live performances, architectural installations, or sequenced shows, MadMapper utilizes dedicated modules to automate playback and transitions:

  • Timeline Automation: This module allows you to program complex, automated event sequences that can be looped or played back at specific times. You can create multiple Timeline Automation modules to target different timelines or cues independently.

  • Timeline Scheduler: Working alongside automation tools, the Timeline Scheduler allows you to activate specific cues or timelines on a recurring or defined internal schedule.

  • Targeting: Specifies the exact Timeline Bank and Timeline to be controlled.

  • Start & End: Allows precise trigger timing down to the Hour, Minute, and Second. It features a critical Stop on Loop End toggle to ensure playback finishes its current cycle cleanly before stopping, rather than cutting off abruptly.

  • Date Configuration: Highly customizable recurring logic allows you to set the Year and Month (to specific times or "Each" for continuous recurrence). The Day Mode (e.g., "By Week Days") offers individual toggles for Monday through Sunday.

  • Logging: The Log section provides real-time feedback when the specified Year, Month, Day, and Time matches the system clock.

Note: The automation features use a 24 hour clock.

Calendar-Based Triggers: The Calendar Scheduler Module

For robust, date-and-time specific automation, the Calendar Scheduler module allows you to trigger scenes and cues at specific dates and times from any calendar application.

Creating Schedule Events

  • Event Naming: In your favorite calendar application, create an event for each scene or cue you want to trigger, with the same name as the scene or cue. 
  • Duration: As only the starting time of the event will be interpreted, you don't need to set a specific duration. 
  • Recurrence: Recurring events (events happening on a repeating schedule) are supported. There is no limit to the number of events or date range you can import. 
  • Bank Organization: Scenes and Cues triggers you import into MadMapper are assigned to the bank of your choice. If you're using several banks, you need to create a separate calendar for each one. This way, there will be no confusion between scenes and cues sharing the same name in different banks.

Exporting and Importing the ICS File

  • Export: Once all your scenes and cues trigger events are set, export your calendar to the standard ICS format. 
  • Creation: In MadMapper, select the Modules tab, next to Outputs tab in the upper left corner. Click on the + button and create a Calendar Scheduler module. 
  • Import: Click on the Import ICS File button and select your previously exported calendar file. Alternatively, you can just drag and drop an ICS file anywhere over the MadMapper interface, and it will be imported into an automatically created Calendar Scheduler Module named after your ICS file. 
  • Offline Functionality: This process is safe: no internet connection is required.

Execution, Timing, and Conflict Rules

  • Event Preview: All the events in your calendar are imported and the 10 first events of your calendar are displayed in the Events section, showing the exact timestamps alongside the parsed event names.
  • Target Configuration: Maps the calendar events to a specific Timeline Bank and includes a Stop on Loop End toggle for smooth, cycle-completed transitions.
  • Recurrence Limits: Please note that recurring events are loaded for the next 365 days each time MadMapper project is reloaded. If your calendar includes events recurring beyond 365 days, you'll have to reload your project before the end of this time range in order for the next occurrences to be loaded. 
  • Sub-Minute Accuracy: If you need to trigger Scenes and Cues at specific times accurate to the second, you can adjust the beginning time of your events ("DTSTART") in the ICS file using a simple text editor. 
  • Conflict Resolution: Multiples iterations of Calendar Scheduler and Cue Scheduler modules can be used at the same time, allowing a wide range of scheduling possibilities. However, please keep in mind that in case of conflict between two triggers (ex: 2 different cues or scenes outputting on the same projector triggered at the same time) the last module on the list (i.e the last one interpreted) will be the one executed. 
  • Logging: The Log panel displays the file path and parsing status. It also includes a Verbose toggle for a more detailed version of the log.

Example ICS File:

BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//MadMapper//Calendar Scheduler//EN
CALSCALE:GREGORIAN
METHOD:PUBLISH
X-WR-CALNAME:MadMapper Bank 1 - Projection Scenes

 

BEGIN:VEVENT
UID:b1-001@madmapper
DTSTART:20260601T170000
SUMMARY:Projector_Warmup
DESCRIPTION:Boot and calibrate all projectors before show time.
STATUS:CONFIRMED
END:VEVENT

 

BEGIN:VEVENT
UID:b1-002@madmapper
DTSTART:20260601T190000
SUMMARY:Opening_Night_Show
DESCRIPTION:Full facade projection mapping sequence. Opening night.
STATUS:CONFIRMED
END:VEVENT

 

BEGIN:VEVENT
UID:b1-003@madmapper
DTSTART:20260601T220000
SUMMARY:Projector_Shutdown
DESCRIPTION:End show and power down projectors.
STATUS:CONFIRMED
END:VEVENT

 

BEGIN:VEVENT
UID:b1-004@madmapper
DTSTART:20260605T190000
RRULE:FREQ=WEEKLY;BYDAY=FR;UNTIL=20260627T235959
SUMMARY:Weekend_Show
DESCRIPTION:Recurring Friday night projection show. Runs every Friday in June.
STATUS:CONFIRMED
END:VEVENT

 

Network Integration: The Startup Timeline Module

In addition to internal scheduling, the Startup Timeline Module provides a streamlined and dedicated way to trigger the playback of a timeline dynamically over the network or upon project launch.

  • Targeting: Allows selection of the specific Bank and the Timeline (e.g., Conductor) to be executed.

  • Delay Controls: Features precise control over execution timing, including a Time (secs) parameter for a hard delay and a visual Countdown tracker to monitor the remaining time before execution.

  • Testing: Includes a dedicated Test button to manually verify the trigger logic and network commands (such as OSC, MIDI, or DMX) before deploying the show.

For synchronized execution across a multi-machine setup, you can broadcast a single network OSC command to trigger multiple MadMapper configurations at the exact same time.
