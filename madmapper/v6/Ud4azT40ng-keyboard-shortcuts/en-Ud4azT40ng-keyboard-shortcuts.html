Media and Projects Tab Panel Tab Navigation

The keyboard shortcuts for the left panel are entirely positional. Cmd/Ctrl + 1 will always open the first tab on the left, Cmd/Ctrl + 2 opens the second, and so on.

By default, the Media Bin is the first tab, resulting in the following layout:

Action Mac Shortcut PC Shortcut
Media Bin Cmd + 1 Ctrl + 1
Video Surfaces Cmd + 2 Ctrl + 2
Laser Surfaces Cmd + 3 Ctrl + 3
DMX Fixtures Cmd + 4 Ctrl + 4
Output Cmd + 5 Ctrl + 5
Modules Cmd + 6 Ctrl + 6
Master Settings Cmd + 7 Ctrl + 7

Note: Because these shortcuts are based on tab position, if you undock the Media pool (View > Separate Media Tab), the remaining tabs simply slide over. Video Surfaces becomes the first tab (Cmd/Ctrl + 1), Laser Surfaces becomes the second (Cmd/Ctrl + 2), and so on.
