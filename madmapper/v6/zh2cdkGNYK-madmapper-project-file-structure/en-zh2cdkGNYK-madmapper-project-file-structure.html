Project File Structure

Project Workspaces

MadMapper 6 introduces a major shift in how projects are saved and managed by moving from standalone project files to Project Workspaces.

Instead of generating a single .mad file that relies on external links to media scattered across your hard drive, MadMapper 6 now creates a dedicated, self-contained local workspace folder for your project with the extension .madproject.

The .madproject Workspace Folder

When you create and save a new project, MadMapper generates a master Workspace folder named [YourProjectName].madproject. By default, this directory is saved to Documents / MadMapper / [YourProjectName].madproject on your computer. Inside this folder, you will find:

  • The .mad Project Files: The core files containing your surfaces, routing, and show data (including your current working file and past saved versions).

  • Auto-Saves Folder: A dedicated subfolder containing your automated backups, keeping your main directory clean and uncluttered.

  • Resources Folder: Contains imported assets specific to the project, such as materials, generators, 3D objects, and other local data.

Collect External Resources

To fully consolidate your project, navigate to the File menu and select Collect External Resources....

When activated, MadMapper automatically gathers all external media you have referenced in your project (video files, audio tracks, images, textures, etc.) and copies them directly into your local .madproject Resources folder.

Workflow Benefits

Transitioning to this workspace structure drastically improves professional workflows:

  • Portability: By keeping everything contained within a single master .madproject folder, you can easily copy the workspace to an external drive. This allows you to open the project on another computer, or hand it off to a collaborator, without ever dealing with broken media links or "missing file" errors.

  • Organization: It acts as a proper production environment, keeping all assets, scripts, and backups strictly organized per project rather than globally scattered across your machine.

  • Archiving: When a live event or installation wraps, you can archive the single folder with 100% confidence that every component of the show is safely backed up together.
