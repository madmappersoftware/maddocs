Software Installation

Download the Installer

The software installation files are only available online, on the MadMapper website.

Download the full MadMapper version (Windows, macOS Intel, or macOS Apple Silicon) in the Downloads section of your user account.

Temporary licenses are always compatible with the latest version !

You can verify the version of your license(s) in your Account's Licenses page.

Regarding extensions: you must download MadMapper. You will need to authorize the extension when activating the software.

Installation

Double-click the .dmg or .exe file you just downloaded.

It will usually be in your “Downloads” folder. If any system dialog boxes appear during installation, simply follow the instructions.

The following installation example is on macOS.

On macOS, you will simply need to drag MadMapper into your Applications folder.

On Windows, the installation process will be the same as for any other software.

If you encounter an issue at this step, we suggest first to re-download the software. Make sure you select the version that is compatible with your computer.

Software Activation

Authorization Manager

Once installed, launch MadMapper and you will first encounter the MadMapper Authorization Manager.

At this step, you can choose to authorize MadMapper or its extensions.

You’ll also find information about the computer on which the software will be used.

Login

The next step requires your MadMapper login and password.

If you have multiple accounts, be sure to use the correct one.

Select License(s)

Next, select the license you want to use on this computer.

This step displays all your available licenses, including the number of computers already authorized, the license version(s), and their serial numbers.

You can also click the Manage button to access the Licenses tab in your user account on the website.

As noted above, temporary licenses can be stored for activation and use at a later time.

 

The following steps follow the same process and will only appear if you have chosen one or more extensions to authorize:

Validation

The next step confirms what will be authorized on this computer:

By clicking on Proceed, you'll have to enter your computer’s session password (not your MadMapper login), and you’ll reach the final step: restarting MadMapper fully authorized.

And then, it's showtime !

 

Deauthorize MadMapper

Logout From MadMapper

Directly from MadMapper, go to the Account menu at the top of the software/screen > Manage Authorizations:

 

 

Choose whether you want to de-authorize (log out) MadMapper and/or its extensions, then follow the steps in the Authorization Manager as you did when activating the software:

You have the flexibility to de-authorize the software or its extensions on one computer to authorize them on another whenever needed, with no restrictions on the number of times you can switch between devices.

You must also deauthorize MadMapper in the following cases:

- formatting or erasing a computer
- activating MadMapper on a new computer if all seats are already in use.

Online Reset

If you no longer have access to a computer you need to de-authorize, you can revoke its authorization remotely using a Reset operation.

 

As the Reset operation is an emergency procedure, its use is limited: if you use a Reset token for one of your licenses, you'll have to wait a year to get your Reset token back for that license.

You can recover a Reset token by launching MadMapper on the computer for which you used the Reset operation.

Update MadMapper

You do not need to log out your license before installing a MadMapper update on the same computer.

 

Updates are checked automatically, and if a new version is available you will be notified when you open MadMapper. Once the installation file for the latest version has been downloaded, you can begin the installation process. If you install a MadMapper update, it will not replace previous versions of MadMapper already installed on your computer.

You can have multiple different versions of MadMapper installed on your computer.

Extensions and Demo Versions

Extensions

The MadLaser and MadProjector extensions do not have dedicated installation files, they require MadMapper to be installed and the extensions to be authorized. You can authorize or deauthorize (log in or log out) extensions at any time using the Authorization Manager.

As a reminder, you cannot use MadLaser or MadProjectorControl as standalone applications. You must own a MadMapper license, either temporary or perpetual.

Demo Version

The installation process for the MadMapper Demo version is identical to that of the full version.


The only differences are:
-The Demo version is not downloaded from the user account but from an email received after submitting a Demo request on this page.
-There is no Authorization Manager with the Demo version.
-You cannot save or launch .mad project files.
