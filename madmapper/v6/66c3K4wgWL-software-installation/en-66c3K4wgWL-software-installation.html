Software Installation

Installing MadMapper is quick and straightforward !

 

On this page, you’ll also find helpful tips on managing licenses and seats, along with best practices to ensure a smooth setup and optimal use of the software.

Download the Installer

First, download the full MadMapper version (Windows, macOS Intel, or macOS Apple Silicon) from the website, located in the Downloads section of your user account.

Temporary licenses are always compatible with the latest version!

Please note that if your license is for instance not a v6 license, you will be able to install version 6 but not activate it.
You can verify the version of your license(s) in your Account's Licenses page.

Regarding extensions: you must download MadMapper.
You will then need to authorize the extension when activating the software.

Installation

After downloading it properly, launch the installer.

On macOS, simply drag MadMapper into your Applications folder.

On Windows, the installation process is the same as for any other software.

If you encounter an issue at this step, we suggest first to re-download the software.

Make sure you select the version that is compatible with your computer.

Splash Screen

Once installed, you can launch MadMapper and you will see this pretty splash screen.

It's the green light to make your MAD dreams come true !

Authorization Manager

Once launched, you’ll first encounter the MadMapper Authorization Manager:

At this step, you can choose to authorize MadMapper or its extensions.

You’ll also find information about the computer on which the software will be used.

The next step requires your MadMapper login and password. If you have multiple accounts, be sure to use the correct one.

Next, select the license you want to use on this computer.

This step displays all your available licenses, including the number of computers already authorized, the license version(s), and their serial numbers.

You can also click the Manage button to access the Licenses tab in your user account on the website.

As noted above, temporary licenses can be stored for activation and use at a later time.

 

The following steps follow the same process and will only appear if you have chosen one or more extensions to authorize:

The next step confirms what will be authorized on this computer:

By clicking on Proceed, you'll have to enter your computer’s session password (not your MadMapper login), and you’ll reach the final step: restarting MadMapper fully authorized.

And then, it's showtime!
