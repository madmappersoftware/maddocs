Software Installation

Installing MadMapper is quick and straightforward !

 

On this page, you’ll also find helpful tips on managing licenses and seats, along with best practices to ensure a smooth setup and optimal use of the software.

Download the Installer

First, download the full MadMapper version (Windows, macOS Intel, or macOS Apple Silicon) from the website, located in the Downloads section of your user account.

Temporary licenses are always compatible with the latest version!

Please note that if your license is for instance not a v6 license, you will be able to install version 6 but not activate it.
You can verify the version of your license(s) at any time by visiting the Licenses page in your account.

Regarding extensions: you must download MadMapper.
You will then need to authorize the extension when activating the software.
