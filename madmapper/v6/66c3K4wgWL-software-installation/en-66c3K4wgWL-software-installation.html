Software Installation

Download the Installer

The software installation files are only available online, on the MadMapper website.

Download the full MadMapper version (Windows, macOS Intel, or macOS Apple Silicon) in the Downloads section of your user account.

Temporary licenses are always compatible with the latest version !

You can verify the version of your license(s) in your Account's Licenses page.

Regarding extensions: you must download MadMapper. You will need to authorize the extension when activating the software.

Installation

Double-click the .dmg or .exe file you just downloaded.

It will usually be in your “Downloads” folder. If any system dialog boxes appear during installation, simply follow the instructions.

The following installation example is on macOS.

On macOS, you will simply need to drag MadMapper into your Applications folder.

On Windows, the installation process will be the same as for any other software.

If you encounter an issue at this step, we suggest first to re-download the software. Make sure you select the version that is compatible with your computer.

Software Activation

Authorization Manager

Once installed, launch MadMapper and you will first encounter the MadMapper Authorization Manager.

At this step, you can choose to authorize MadMapper or its extensions.

You’ll also find information about the computer on which the software will be used.

Login

The next step requires your MadMapper login and password.

If you have multiple accounts, be sure to use the correct one.

Select License(s)

Next, select the license you want to use on this computer.

This step displays all your available licenses, including the number of computers already authorized, the license version(s), and their serial numbers.

You can also click the Manage button to access the Licenses tab in your user account on the website.

As noted above, temporary licenses can be stored for activation and use at a later time.

 

The following steps follow the same process and will only appear if you have chosen one or more extensions to authorize:

Validation

The next step confirms what will be authorized on this computer:

By clicking on Proceed, you'll have to enter your computer’s session password (not your MadMapper login), and you’ll reach the final step: restarting MadMapper fully authorized.

And then, it's showtime !
