Extensions and Demo Versions

Extensions

The MadLaser and MadProjector extensions do not have dedicated installation files, they require MadMapper to be installed and the extensions to be authorized.

You can authorize or deauthorize (log in or log out) extensions at any time using the Authorization Manager.

As a reminder, you cannot use MadLaser or MadProjectorControl as standalone applications.

You must own a MadMapper license, either temporary or perpetual.

Demo Version

The installation process for the MadMapper Demo version is identical to that of the full version.


The only differences are:
- The Demo version is not downloaded from the user account but from an email received after submitting a Demo request on this page.
- There is no Authorization Manager with the Demo version.
- You cannot save or launch .mad project files.
