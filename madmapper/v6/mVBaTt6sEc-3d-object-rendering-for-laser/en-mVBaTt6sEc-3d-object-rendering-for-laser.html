3D Object Rendering for Laser

The Laser 3D surface allows you to import standard .OBJ files and project them as high-definition volumetric wireframes.

Laser 3D Settings

  • 3D Model: Select a built-in primitive shape or import your own .OBJ file. Adjust Face Culling to hide the back sides of objects, drastically optimizing laser rendering by preventing the scanner from drawing lines you can't see.
  • Texturing: Define how textures and colors map to the Object UVs.
  • Calibration: Use the Calibrate toggle and Fix Position button to accurately align the 3D rendering with real-world physical objects.

Process (For 3D Objects)

Controls the volumetric rendering output.

  • Set the Mode (e.g., Depth), and fine-tune the Sensibility and Definition to control exactly how much geometric wireframe detail is sent to the laser.
