DMX Fixtures - Import / Export from SVG

MadMapper 6.1 comes with Bézier Fixtures which allows new possibilities for importing fixtures from SVG. While MadMapper 5 was only import "line" elements from SVG, MadMapper 6.1 can load "line","rect","circle","ellipse","polygon","polyline","path".

 

Also in MadMapper 6.1 a fixture definition can be set to LED Strip mode or LED Matrix mode. In this case, you can specify the strip length (or matrix size) for each fixture. So if you have a strip with 160 pixels, one with 165, one with 100 pixels, they can all use the Fixture Definition « LED Strip RGB » and you specify the size for each Fixture. Same for matrices.

 

We've also added options to specify fixtures parameters directly your your vector file editor (ie Illustrator, Inkscape etc.). For instance DMX patching (universe / channel) can be specified from the layer "id" exported in SVG file. It is also possible to generate an SVG from a script or with an AI and add DMX patching info as XML tags of the geometry elements in the SVG.

Another improvement : when imported from SVG, layer groups in the SVG will generate fixture groups in MadMapper, it will respect and reproduce the hierarchy.

 

Exporting fixtures to SVG and importing it in a new project will recreate the original setup (fixture types, geometry, line/circle thickness, DMX patching (universe / channel), group hierarchy etc. This make new workflows easy:

  • Create fixture setup in MadMapper, export as SVG and use it in a software like After Effects to create a video animation easiely that will perfectly match fixtures.
  • Create fixture setup in an SVG file from a vector editor (Illustrator) or with an AI and import it, it can also be used in a video editing software to create content.

This document describes how an SVG file will be interpreted by MadMapper when using File / Import Fixtures and choosing an SVG file (CSV import has not been modified).

Additional settings extracted from "id"

The id of a layer can include all necessary parameters to create the fixtures. If the layer id is « MySuperLedStrip », it will just create a fixture with name «  MySuperLedStrip » (fixture type will be deduced from svg geometry type : line, rect etc.).

 

But the id can include extra info. For instance if the id is « MySuperLedStrip__UN__10__CH__12 », the fixture name will be « MySuperLedStrip » and MadMapper will set UNiverse to 10 and CNannel to 12.

Supported data

- « __UN__ » : Universe number (0-32767)

- « __CH__ » : Channel number (1-512)

- « __FT__ » : Fixture Type to create. Possible values : « fixture_bezier », « fixture_line », « fixture_circle », « fixture_quad »

- « __FD__ » : Fixture Definition, for instance « Generic – Pixel RGB » or « GarageCube - SFX-01 W 1m » (Group[space]-[space]Name)

- « __SL__ » : Strip Length (for fixture definition set to LED Strip mode)

- « __MW__ » and « __MH__ » : Matrix Width / Height (for fixture definition set to Matrix mode)

- « __TH__ » : Thickness in pixels of the line & bezier, or thickness pourcentage for circle fixture

Additional settings in XML elements

This data can also be added as attributes of the geometry XML element if editing from a text editor / script or with an AI, it avoid having very long and cryptic Ids:

- « universe » : Universe number (0-32767)

- « channel » : Channel number (1-512)

- « fixture_type » : Fixture Type to create. Possible values : « fixture_bezier », « fixture_line », « fixture_circle », « fixture_quad »

- « fixture_definition » : Fixture Definition, for instance « Generic – Pixel RGB » or « GarageCube - SFX-01 W 1m » (Group[space]-[space]Name)

- « strip_length » : Strip Length (for fixture definition set to LED Strip mode)

- « matrix_width » and « matrix_height » : Matrix Width / Height (for fixture definition set to Matrix mode)

- « thickness » : Thickness in pixels of the line & bezier, or thickness pourcentage for circle fixture

What fixture type will be created

- If « fixture_type » (« __FT__ ») is specified, MadMapper will create a fixture of the chosen type (refer to previous section)

- If the SVG geometry element is a « line » MadMapper will create an « Fixture Line » surface

- If the SVG geometry element is a « rect » and is not rounded (with rx & ry), MadMapper will create an « Fixture Quad » surface

- For any other type it will create a « Fixture Bezier »
