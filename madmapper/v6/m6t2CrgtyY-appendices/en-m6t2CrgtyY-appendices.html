Appendices

Appendix A: Comprehensive Keyboard & Mouse Shortcuts

A complete, printable cheat sheet of all global, interface, and tool-specific shortcuts for both macOS and Windows, including hidden modifier keys for precise mesh warping and masking.

 

Appendix B: Master OSC Command Directory

A full table of every Open Sound Control (OSC) address available in MadMapper 6. This includes syntax examples for triggering cues, manipulating surface opacities, sending text strings to text generators, and controlling the master timeline via external software (like TouchDesigner, QLab, or Ableton Live).

 

Appendix C: Supported Media Codecs & Formats

A technical breakdown of recommended video codecs for performance optimization.

  • Includes rendering guidelines for HAP / HAP-Q / HAP Alpha (for CPU/GPU efficiency).

  • Details on Apple ProRes, DXV3, and MP4 (H.264/H.265) handling.

  • Supported image formats (PNG, JPG, SVG, TIFF) and 3D object limits (.OBJ).

 

Appendix D: DMX Fixture Profile Creation

A technical guide for writing custom .mmf (MadMapper Fixture) files. Includes the XML schema required to build profiles for unlisted generic Chinese LED fixtures, moving heads, or custom kinetic winches.

 

Appendix E: Network Optimization for AVB, NDI, and Art-Net

A deep dive into IT and network setup for massive shows.

  • Subnet mask and IP address configurations for isolating Art-Net/sACN traffic from NDI video traffic.

  • Recommended gigabit switch settings (IGMP Snooping, QoS).

  • Troubleshooting dropped packets and latency in pixel-mapped LED arrays.

 

Appendix F: MadLaser Hardware Compatibility & Setup

A technical lookup table of supported laser mainboards and DACs (Digital-to-Analog Converters), including setup instructions for:

  • EtherDream

  • ShowNET (Laserworld)

  • Helios USB

  • LaserCube (WiFi/Ethernet)

  • Pangolin FB4 (via Beyond / OSC bridge)

 

Appendix G: Native GLSL Shader Variables

A reference guide for code artists writing interactive materials. Lists all native uniforms automatically passed by MadMapper into the shader environment (e.g., RENDERSIZE, TIME, BPM, AUDIO_FFT).
